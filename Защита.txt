ЗАДАНИЕ 1, ПУНКТ 4: «Написать конфигурационный файл».
Открой .circleci/config.yml:
version: 2.1 — версия синтаксиса конфигурации CircleCI.
jobs — отдельные задания; у нас test и style.
docker / image — среда c Python 3.11: cimg/python:3.11.
checkout — получение исходников из GitHub.
run «Установка зависимостей» — pip install -r requirements.txt.
run «Запуск тестов pytest» — выполнение всех тестов.
store_test_results — сохранение JUnit XML для вкладки тестов.
store_artifacts — возможность скачать XML как файл.
Скажи: «Команды выполняются по шагам. Если pytest возвращает ненулевой код,
задание становится красным. В конфигурации нет подавления ошибки».

ГДЕ ВЫБИРАЮТСЯ ЦИФРЫ
start.ps1: Read-Host читает пункт меню лабораторной, switch запускает команду.
app.py: input читает пункт калькулятора, if/elif выбирают математическую функцию.
start.cmd — короткий запуск PowerShell. .vscode/tasks.json — настройка Ctrl+Shift+B.
Сам CircleCI использует config.yml и не запускает наше меню Windows.

КОНТРОЛЬНЫЕ ВОПРОСЫ
1. CI/CD — автоматизация проверок и доставки изменений. CI проверяет новый код,
Continuous Delivery готовит выпуск с ручным развёртыванием, Deployment развёртывает автоматически.
В этой лабораторной настроена CI-часть, автоматического развёртывания на сервер нет.
2. Конфигурация CircleCI — YAML, файл .circleci/config.yml. Отступы задают структуру.
3. Jobs описывает отдельные задания, их окружение и шаги. Workflow объединяет задания.
4. Раздельные шаги помогают понять, где ошибка: в установке пакетов или в программе.
5. Приватный репозиторий доступен через разрешения GitHub App или OAuth-интеграцию.
У нас публичный репозиторий и существующее подключение аккаунта к CircleCI.
6. В старой CircleCI CLI 0.1.x отдельный job можно было выполнять локально через
Docker, но не весь workflow; кэширование тоже было ограничено. В актуальной CLI v1
команда local execute удалена. В нашей работе локально запускаются сами pytest
и Black, а полноценный workflow выполняется в облаке CircleCI.
Источник: https://circleci.com/docs/guides/toolkit/cli-migration-guide/
